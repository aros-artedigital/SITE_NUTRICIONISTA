## 📌 Sobre o Projeto

A **RafaelNutri** é uma *landing page* moderna, responsiva e acessível desenvolvida para apresentar os serviços do nutricionista clínico **Rafael Souza**. O site tem como objetivo principal conectar pacientes a um acompanhamento nutricional personalizado e sem extremismos, facilitando o agendamento de consultas presenciais (Uberlândia - MG) e online.

🌐 **Acesse o site ao vivo:** [https://homenutre.netlify.app/](https://homenutre.netlify.app/)

---

## ✨ Funcionalidades e Seções

- **Hero / Apresentação:** Chamada principal direcionada para agendamento rápido via WhatsApp.
- **Sobre o Nutricionista:** Breve histórico profissional e pilares do atendimento (individualizado, sem fórmulas prontas).
- **Especialidades:**
  - 🏋️‍♂️ *Emagrecimento saudável*
  - 🥗 *Reeducação alimentar*
  - 🔬 *Saúde metabólica*
  - ⚡ *Nutrição esportiva e estética*
- **Diferenciais & Processo de Atendimento:** Etapas explicativas desde a primeira consulta até o acompanhamento continuado.
- **Currículo & Formação:**
  - Graduação em Nutrição (UFU)
  - Especialização em Nutrição Clínica (HC-UFU)
  - +800 pacientes atendidos
- **Mockup Interativo de Atendimento:** Simulação visual de interação via WhatsApp para humanizar a jornada do usuário.
- **Integração com WhatsApp:** Botões de *Call To Action* (CTA) em pontos estratégicos direcionando para o agendamento direto.
- **Design Totalmente Responsivo:** Layout otimizado para dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semantic:** Estruturação semântica e focado em acessibilidade (`aria-labels`, navegação por teclado).
- **CSS3 / CSS Moderno:** Flexbox, CSS Grid, variáveis CSS e design responsivo (Mobile-First).
- **Google Fonts:** Tipografia personalizada para melhor leitura e identidade visual.
- **Netlify:** Hospedagem e *deployment* contínuo da aplicação.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/homenutre.git
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd homenutre
   ```

3. **Abra o arquivo `index.html`:**
   - Você pode abrir diretamente no navegador ou utilizar extensões como o **Live Server** no VS Code.
